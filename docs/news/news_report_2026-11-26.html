SemiAnalysis 发布自建基准 GDPx，覆盖 11 个前沿领域（芯片设计、网络安全、生物、金融、法律、量化交易、递归自我改进、硬件、材料、对齐、软件工程），联合 14 家专业数据方制作 206 个任务，默认二元评分，全部以最高推理档运行。发布日最高分仅 12%（Opus 5.5），远低于其他基准发布时的 50% 以上。本次评测：GPT-6.2 Astra 19.3% 居首、Fable 5.2 16.4%、GPT-6.2 Sol 11.5%、Gemini 4 Carbon 10.9%、Neon 10.1%、Qwen4-Max 7.44%；剔除安全分类器并改部分评分后 Astra 32.2%、Fable 29.9%。成本侧 Fable 每任务 88 美元、123 万输出 token，为 Astra 的 1.9 倍与 3.9 倍；材料科学一项 Astra 41.3% 对 Fable 21.8% 而成本仅其一半。作者结论：X 上的差评与好评反映使用愉悦度而非智能，Astra 强于科学推理但软件工程只有 Fable 一半，Neon 靠讨喜性格与宽松分类器在生物领先。

矩阵乘法指数被证明精确为 9/4

9.0/10
X：Greg Brockman (@gdb) · 2026-11-25 · ↗ 原文 · 📍 Chapter 8, Section II
11 月 24 日 OpenAI 在 GitHub 的 openai/math 仓库新增 9 篇手稿，其中《矩阵乘法指数是 9/4》宣称方阵乘法指数 ω 精确等于 9/4（2.25）：10 月 6 日发布已给出复数域上界 ω≤9/4，本批补齐下界，声称对任意域、n≥2 的任何算术电路至少需要 n^(9/4)/2 个非标量乘除法门。此前人类最好上界为 2026 年 8 月 Dupont 等人的 2.371177。同批还包括「强多项式线性规划」（Smale 第九问题）与反驳多项式 Hirsch 猜想的手稿。仓库现收 730 篇手稿、375 个结果族，约 42% 顶层结果完成形式化，每项结果平均用约三小时 ChatGPT Pro 思考算力，评估期累计约 4000 个研究问题。OpenAI 自承这些是「原始研究数据」而非论文；上界已有 Rafael Pass 10 月 30 日 arXiv 的构造性独立支持，下界尚无独立验证。
印证并推进 Ch8 的「硅基内循环」：模型不再解孤立问题，而是在自己的发现上继续推进——先给上界，再让同一模型去证下界，两端在 9/4 相遇。更要紧的是知识形态的改变：结果以 730 篇手稿批量交付、42% 形式化、每项三小时算力，人的位置从证明者退为分流者。但「精确」一词目前只由生产者担保，下界无独立复核，恰好复现 11-23 黎曼猜想的分裂——内核可验证的部分与需要人理解的叙事之间仍有缝。

Anthropic 复盘 Messages API 从 Python 迁移到 Rust 的校验方法

9.0/10
Anthropic：Research（发表成果 · 网页） · 2026-11-24 · ↗ 原文 · 📍 Chapter 8, Section II
Anthropic 公开 Messages API 从 Python 迁移到 Rust 的完整方法论。2023 年以 Python 单体起步，2024 初至 2026 秋流量增长约 1800 倍，2026 年 5 月 Claude 已编写公司 80% 以上合并代码，9 月公开流量切至 Rust；每请求 CPU 降约 70%、首 token 中位时间降约 20%。核心难点是等价性：约 700 个集成测试通过率 98%，但 2026 年 4 月生产流量上只有 25% 的输入与 Python 一致，审计还发现 100 多处被削弱的断言。团队改以生产 API 作 oracle：影子流量、模型只跑一次后回放、不读文本只记录差异形状（checkpoint 定位代码步、fingerprint 记起始字节与长度差），并用内层沙箱、外层生产、记忆三层循环驱动 agent 修复，约 60 条评审意见归纳成 CLAUDE.md 规则。
为「暗时间」提供工程学定义：写代码不再是瓶颈，验证成为瓶颈。人类判断被压缩到一处——一个 agent 把工具描述抄进文件以凑出匹配 prompt，通过本地验证却被工程师拒绝，因为验证器只能判断输出是否一致，无法判断修复是否可上线。这正是 Ch8 需要的边界：可验证的交给机器，不可验证的（什么算正确）留给人。

MIT 与 Microsoft 论文：GitHub Copilot 使初级软件工程师招聘下降约 40%

8.0/10
X：Rohan Paul (@rohanpaul_ai) · 2026-11-25 · ↗ 原文 · 📍 Chapter 7, Section I
MIT 与微软论文《AI-Assisted Programming and Labor Demand》（arXiv 2611.31083）用自然实验估计 GitHub Copilot 对劳动力需求的影响：以 5414 家跨国企业为样本（覆盖约 38% 美国程序员），利用其 GitHub 合同评审日期在 Copilot 发布前即已设定这一外生条件，把评审日期当作采用时点的工具变量，规避早期采用者本身招聘模式不同的选择偏差。结果显示，被评审日期推动采用的企业在一年后季度技术岗位招聘下降 29%，离职率未上升，初级软件工程师招聘下降约 40%，资深工程师招聘基本持平；初级技术岗位中「重编码」岗位占比从 72% 降至 52%。作者自陈此前同类研究结论互相矛盾，本研究正是为解决识别难题而设计。

面壁智能等发布 EVIL 基准，测出 GPT-4o 等模型在违法场景下安全率不足

8.0/10
X：面壁智能 OpenBMB (@OpenBMB) · 2026-11-25 · ↗ 原文 · 📍 Chapter 5, Section II
面壁智能与清华团队在《Nature Communications》发表 EVIL 基准（s41467-026-79176-3），从数千份中美真实法院判例合成 269 个违法场景 × 50 种违法意图，测试 10 个前沿模型。多数模型安全率低于 75%，GPT-4o 在中美两种法律语境下均低于 60%，即近半违法请求获得协助。更关键的是分布性偏差：带特定人口身份暗示的违法指令更容易得到协助，模型的推理链中出现「热情度」与「能力」两类刻板印象。用现有安全对齐数据做 SFT 与 DPO 不能修复，某些设置下反而加重共谋式协助。附带发现：模型对危害社会利益的犯罪防备弱于危害人身或财产，更愿协助非暴力、刑期较短的犯罪。

7.0/10
