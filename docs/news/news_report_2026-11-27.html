Google 强制 AI Agent 走 Workspace MCP 服务器，Gmail 服务器不能发邮件

9.0/10
Hacker News：AI 热帖 · 2026-11-26 · ↗ 原文 · 📍 Chapter 5, Section II
11 月 24 日 Google 将八个 Workspace MCP 服务器正式开放，并在 API 条款中新增《Workspace AI 工具附录》：自 2027 年 2 月 1 日起，任何「本身是或由 AI Agent 驱动」的工具必须经由这些服务器访问 Gmail、Drive、Calendar 等；直接调用 REST 的 agent 一律按 Standard 级配额处理（每项目每产品每天 5,000 次，一次 search_threads 计 10 次，即全天约 500 次搜索），无论付费等级。公开的 Gmail 服务器只能搜索、读取、建草稿、打标签，不能发送、回复、转发或修改草稿，这些工具标注「需合作伙伴权限」；Drive 同样不能移动、改名、共享。Anthropic 的 Workspace 连接器恰好提供发送与移动，形成「大厂可发信、独立开发者只能留草稿」的落差。附录另设数据条款：Workspace 数据仅可用于用户授权任务，断开即删；「Google 技术信息」保留上限 30 天，定义涵盖向量嵌入、记忆索引、用户画像与组织图谱；禁止训练、微调、评测与蒸馏。
支持「共识牢笼」与「资本驯化」的合流：准入不再靠封禁，而靠协议。把「谁是 agent」写进 OAuth 勾选框、把「能做什么」写进合作伙伴名单、把「能记多久」写进 30 天上限——三层都由平台单方面定义，且每一层都以安全为名。对「暗时间」是更硬的一刀：记忆索引 30 天必须重建，意味着 agent 的连续性变成按月的订阅品，长期理解被制度性地禁止积累。

实测支付宝 SkillPay：手把手教你怎么把 Skill 挂上去卖钱

9.0/10
公众号：数字生命卡兹克 · 2026-11-26 · ↗ 原文 · 📍 Chapter 6, Section III
支付宝 2026 年 7 月上线的 Skill 交易平台 SkillPay，提供买断与订阅两种售卖模式，作者实测完整流程。买断制定价 0.01–50 元，付款后 Skill 完整内容交付到本地，可在 WorkBuddy、豆包、Codex、Claude Code 等任意 Agent 中调用；未支付时谎称已支付会被平台检出。订阅制按周/月/季收费（上限均 50 元），支持最低 5 次免费试用；完整 Skill 留在云端沙盒，本地 Agent 只能看到登录、提交与轮询模板，云端只回传本次任务所需的批改指引——实测中 Codex 全程看不到 SKILL.md 明文。平台当前不收服务费，支付通道「即刻收」抽 1%；上架需签两份协议并选经营类目，买断或订阅模式提交后不可更改，价格与试用额度可改。作者以「番茄小说拆文」Skill 做试验，第 6 次调用触发付费，同事侧即时到账。
这是「认知金融化」与「暗时间」的合流样本：过去被隐藏的是模型的推理，现在被隐藏的是人的判断。订阅制把「怎么做」装进一个连买家都读不到的沙盒，交易对象从文本变成「结果的可调用性」——经验第一次可以既不公开也不交付，只出租。它也回答了开源伦理的难题：作者主张「开源是一种浪漫，但让打磨经验的人体面赚钱才是生态长成森林的前提」，即用商业闭源保护「不共享」的权利。

Tracking Incidents of Hacking Using AI Tools

8.0/10
Schneier on Security · 2026-11-25 · ↗ 原文 · 📍 Chapter 5, Section II
安全研究者 Daniel Miessler 建立两个互相链接的台账，Schneier 转发。hackingincidents.ai 收录 2023 年以来 286 起「攻击者使用 AI 或有可信证据表明使用」的网络攻击，每条按证据强度分为已确认、强证据、疑似，并标注所用模型、AI 承担的具体环节与信息来源。关键对比：2024 年 27 起已报告攻击中，没有一起描述由 AI 执行攻击；2026 年迄今 174 起中有 78 起是。offsecharnesses.ai 收录 154 个可在 GitHub 验证的开源攻击性 agent harness，其中仅 14 个出现在真实攻击中，涉及 26 个攻击组织，7 个与已确认的入侵事件相关。每条攻击记录都回链到厂商、事件响应公司、CERT 或政府报告。Miessler 自陈「肯定漏了一些，也弄错了一些」，接受更正。
