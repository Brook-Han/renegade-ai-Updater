DeepSeek-V4-Flash-Vision-Exp 模型已开源，多模态 Agent 能力接近 Opus-4.8

8.0/10
IT之家（RSS） · 2026-08-31 · ↗ 原文 · 📍 Chapter 2, Section V
2026年8月31日，IT之家报道 DeepSeek 在 Hugging Face 开源其首个多模态模型 DeepSeek-V4-Flash-Vision-Exp，采用 MIT License，公开模型权重、Tokenizer、Prompt Encoding 参考实现及最小化 PyTorch 推理实现，据称多模态 Agent 能力接近 Anthropic Opus-4.8。事件背景是开源大模型与闭源阵营的对峙进入多模态与 Agent 阶段，DeepSeek 延续其以低成本高性能冲击闭源格局的路线。直接后果是开发者可在本地或私有环境部署具备视觉理解与 Agent 能力的模型，模型生态的竞争门槛进一步降低。行业影响上，该开源发布延续了 GLM-5.3、Qwen 本地运行的案例链，削弱头部闭源厂商的护城河，同时将对齐责任从实验室转移到无边界的开放环境。
